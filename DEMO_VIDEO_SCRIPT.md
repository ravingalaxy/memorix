## ⏱️ Video Walkthrough & Script Timeline

### 0:00 – 0:30 | Hook & The Multi-Agent Amnesia Problem
- **Screen Action:** Open `https://memorix-dcaq.onrender.com/` in full-screen. Show the dark cyberpunk Neural Canvas dashboard with real-time stats and graph visualizer.
- **Voiceover:**
  > "Welcome to Memorix — a production-grade Multi-Agent Memory and Coordination Platform built for Track 02: Agent Memory and Coordination.
  > Today's AI agents suffer from acute amnesia. Context windows are ephemeral, and when multiple agents collaborate, they lose shared state across sessions. 
  > Memorix solves this by implementing the complete Trinity of Memory: Episodic, Semantic, and Procedural memory, natively orchestrated on FalkorDB."

---

### 0:30 – 1:10 | Episodic Memory Across Disconnected Sessions
- **Screen Action:** Left sidebar → Click **"Scenario 1: Multi-Session Support"**. Watch toast notification, timeline updates, and session nodes populate in the graph.
- **Voiceover:**
  > "Let's load our Multi-Session scenario. 
  > Notice how Memorix captures Episodic Memory: every conversation turn, session lifecycle, and participant agent is chronologically indexed in FalkorDB.
  > Even when sessions occur hours apart, agents retain complete temporal awareness with zero context loss."

---

### 1:10 – 1:50 | Semantic Memory & Cross-Session Recall
- **Screen Action:** In the center panel, click on **Semantic Memory Repository** or query `Alice Robertson`. Show the connected entities and verified facts.
- **Voiceover:**
  > "Next, Semantic Memory. As agents interact, Memorix extracts verified entities and facts into a long-term knowledge graph. 
  > When an agent encounters customer Alice Robertson, it instantly recalls her Gold Tier status and customized parameters, enabling hyper-personalized responses across independent sessions."

---

### 1:50 – 2:25 | Procedural Memory & Adaptive Playbooks
- **Screen Action:** Right panel → Select **"Gold Tier Customization"** from the Procedural Memory database. Show the execution count (1,470), success rate (94%), and step-by-step procedure.
- **Voiceover:**
  > "Third, Procedural Memory. Memorix allows agents to learn, store, and refine reusable execution workflows as skills. 
  > Here, our Gold Tier Customization playbook tracks execution counts, duration metrics, and a 94 percent success rate, continuously improving multi-agent efficiency."

---

### 2:25 – 3:00 | Real-Time Agent Handoffs & Multi-Tenant Isolation
- **Screen Action:** Click an agent node in the graph, open the **Coordination Handoff** dialog, and submit a handoff from `CustomerBot` to `KnowledgeBase`. Point out the multi-tenant dropdown (`tenant_corp` vs `tenant_demo`).
- **Voiceover:**
  > "Finally, observe real-time Agent Coordination. 
  > When CustomerBot hands off a request to KnowledgeBase, Memorix records an immutable handoff node in FalkorDB with full context preservation.
  > With dedicated graph namespaces for multi-tenant isolation and sub-100 millisecond GraphBLAS queries, Memorix delivers enterprise-grade memory coordination. Thank you."
